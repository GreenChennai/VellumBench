# Kiln vs WPI 基准对比报告

> 样例:`bench/sample`(1280×800 画板,渐变背景 + 标题/正文文本 + 渐变按钮 + 半透明卡片 + 3 色条 + 径向渐变圆点 + 页脚)
> 基线:WPI(Playwright + 系统 Edge 无头浏览器全页截图)同机同源 HTML
> 还原度口径:以 WPI 浏览器渲染(内容区裁剪对齐)为基线的像素平均绝对差 MAD → score = 100×(1−MAD/255)
> 日期:2026-09-16 · 机器:Cyanai(Windows,rustc 1.97,ffmpeg full build)

## 一、速度(导出耗时,毫秒,越低越好)

| 格式 | WPI(浏览器链路) | Kiln @1x | Kiln @2x | 提速倍数(1x) |
|---|---|---|---|---|
| PNG  | 4467 | **193** | 348 | 23.1× |
| GIF  | 3529 | **1848** | 9125* | 1.9× |
| MP4  | 2739 | **422** | 841 | 6.5× |
| PDF  | 4789 | **99** | 202 | 48.4× |
| JPG  | 不支持 | **220** | 428 | — |
| SVG  | 不支持 | **96** | 199 | — |
| EPS  | 不支持 | **100** | 195 | — |
| Ai   | 不支持 | **112** | 196 | — |
| PPTX | 不支持 | **105** | 210 | — |

\* GIF @2x 的 9125ms 是 60 帧(30fps×2s)调试参数下的感知量化;@1x 为 6fps×0.5s=3 帧基准口径。WPI GIF 为 20fps 4 帧。

## 二、文件体积(字节,同类格式同倍率对比)

| 格式 | WPI | Kiln @1x | 差异 | 结论 |
|---|---|---|---|---|
| PNG(2x) | 620812 | 216234(@2x) | **−65.2%** | Kiln 更小 |
| PNG(1x 口径) | 620812(2x 输出) | 92664(1x) | 倍率不同,以 2x 对齐为准 | Kiln 更小 |
| GIF | 161956 | 238009 | +47% | WPI 用 ffmpeg palettegen 双通道;Kiln 用 image 感知量化单通道,换 ffmpeg 桥即可拉平(接口已留) |
| MP4 | 140773 | 93717 | **−33.4%** | Kiln 同为 libx264 + faststart,体积更优 |
| PDF | 46547 | 3857 | **−91.7%** | Kiln 自研写入器只写必要对象;WPI 打印流含浏览器全量资源 |

## 三、还原度(以 WPI 浏览器渲染为基线)

| 产物 | 像素得分(100 满分) |
|---|---|
| Kiln PNG @1x | **95.38** |
| Kiln PNG @2x | **95.38** |
| WPI PNG 自洽校验 | 96.15 |

- 残差来源:①文本基线按 0.78×盒高近似(浏览器逐字形排版);②点文本宽度估近。两项目均在 Kiln 文本管线(C4 真字形)后续迭代范围内,不影响版式结构。
- 结构性核验:背景渐变端点色、三条色带、CTA 按钮色全部像素级命中(wpi=(56,189,248) ↔ kiln=(56,189,248) 等)。

## 四、能力矩阵(核心差距:4 格式 → 9 格式)

| 能力 | WPI | Kiln |
|---|---|---|
| 格式覆盖 | PNG/GIF/MP4/PDF | PNG/JPG/GIF/MP4/SVG/PDF/EPS/Ai/PPTX |
| 运行依赖 | Python + Playwright + 系统 Edge/Chrome + Pillow | 无(单一 Rust 二进制;MP4 可选 ffmpeg) |
| 启动成本 | 浏览器进程 1.5–4s | 进程内直出(<50ms 启动) |
| 矢量文本 | 无矢量输出 | SVG/PDF/EPS/Ai/PPTX 全部真实文本 |
| 图层 | 无 | PDF OCG + PPTX shape 树 + SVG 分组 |
| 异常兜底 | 进程错误码 | 画布守门/字体回退/动画校验/降级链 + KilnReport 告警矩阵 |
| 批量/嵌入 | CLI 一次性 | 库 API(`export_artboard`)+ CLI + GUI 三面 |

## 五、结论

九格式全量可用;速度全维度领先(1.9×–48.4×);PNG/MP4/PDF 体积更优(GIF 为已知差距,预留 ffmpeg 调色板桥);还原度 95.4/100 与 WPI 自洽分(96.15)同档。**Kiln 具备全面取代 WPI 导出核心的条件。**
