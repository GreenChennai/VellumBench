# ADR-0040: 自动保存与崩溃恢复采用项目内 .vb-autosave/ 快照

- 状态:已接受(阶段 7 / 副文档 07-1;用户拍板 Z1 按推荐;兑付迭代附录
  ADR-VB-L08,主文档 W11)
- 背景:实测完全没有自动保存 / 恢复 —— 一次异常退出即丢全部未保存改动,
  编辑器不具备"日常敢用"的门槛。
- 决策:
  1. 有未保存改动时周期写**项目内** `.vb-autosave/<doc>.json`(滚动快照
     ×3;间隔可配置,默认 60s,`edit.autosave_interval` 调档入
     `workspace.json`);**绝不覆盖 `index.html`** —— 与项目一起备份 / 迁移;
  2. 打开项目(含 --project 直开 / 主页打开 / 会话恢复)检出快照残留 →
     「恢复 / 丢弃 / 查看差异 / 暂不处理」;查看差异 = 磁盘 vs 快照 vs 内存
     三方只读对比(内存不可比时如实标注);
  3. 「恢复」载入内存并清空撤销栈;门禁出图模式禁用自动保存(确定性优先);
  4. 响应式渲染保底:脏态节拍自身挂 ≤500ms 重绘请求(干净态零开销,
     不给 idle 节流添负担)。
- 落地:`crates/vb_app/src/autosave.rs`(纯文件层:信封 / 滚动 / 损坏回退 /
  LCS diff)、`crates/vb_app/src/app/recover.rs`(节拍 + 恢复 GUI +
  强杀恢复 e2e)。
- 取舍:项目目录多一个隐藏目录(配合 .gitignore 提示);换来数据安全。
- 被否决替代:(a) 全局 `%APPDATA%` 快照(项目迁移即丢);(b) 不做
  自动保存(不可接受)。
