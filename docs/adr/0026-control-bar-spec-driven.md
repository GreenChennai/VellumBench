# ADR-0026: 控制面板由工具"声明规格",统一渲染

- 状态:已采纳(2026-09-21 复核确认)
- 背景:AI 的"控制面板"(紧随菜单栏、**随当前工具/选区变化**的上下文条)是招牌
  交互。若每个工具各画各的,会出现"同一字段两处不同口径"的漂移
  (`design/03 §三`;副文档 02-2)。
- 决策:
  1. 新增统一的控制面板(`Panel::top("control_bar")`,高 = `space::CONTROL_BAR_HEIGHT`);
  2. 工具/选区**只声明**规格(`ControlPanelSpec` + `CtlWrite`),由控制面板统一
     渲染成控件;写入一律落到命令层(`SetStyle` / `SetGeom` / 各面板构建器);
  3. 面板**不持有状态**:每帧从文档回读投影(与外观/渐变/透明度面板同一纪律)。
- 实现:`crates/vb_app/src/app/control_panel.rs`(`pub` 暴露 spec 类型与
  `PROP_GROUPS` 供集成测试)、`crates/vb_app/src/app/panels/properties.rs`(属性 Tab)。
- 验证:控制面板的字段规格与写入路径有单测(`control_panel` 模块内的纯函数测试);
  属性面板与浮窗面板读写**同一批命令**(同源)。
- 理由:控制面板是"最高频入口",一旦各工具自绘就会形成第二套真相;
  "声明规格 + 统一渲染"把新增字段的成本压到一行数据。
- 后果:新增工具若需要特有字段,应扩展 spec 而不是在工具里画 UI。
- 关联:副文档 02;ADR-0025(面板只读投影)。
