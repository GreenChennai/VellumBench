# ADR-0033: 启动流程采用独立主页窗口,--project 直达项目窗口

- 状态:已接受(阶段 2 / 副文档 02-1;兑付迭代附录 ADR-VB-L01,主文档 W1/W2)
- 背景:迭代实测(主文档 P0-①)启动直接进空文档或 argv 项目,无最近项目、
  无新建入口 —— 「打开软件第一眼」是一块空画布。目标③要求"先进入主页"。
- 决策:
  1. 默认启动(无参数)进入**独立主页窗口**(最近项目 / 新建 / 打开 /
     模板 / 恢复会话);主页是外壳(`ShellApp`)的根视口内容,不是编辑器
     内的欢迎标签页;
  2. `--project <dir>` / 位置参数(目录或 .html)/ 拖拽 / 关联文件**直达**
     项目窗口,不过主页 —— 老用户高频重启可绕过(主文档 W2);
  3. `--help` / `--version` 保留,脚本与 CI 用法不破坏。
- 落地:`crates/vb_app/src/shell.rs`(`Launch` 解析:`Home` / `Project` /
  `Shot`;`run_native` 根视口构建器按启动模式选择)、`main.rs`(分发)、
  `crates/vb_app/src/launcher.rs`(主页 UI)。
- 取舍:多一层窗口与状态管理;换来"有入口、可恢复、可发现"。
- 被否决替代:(a) 编辑器内欢迎标签页(与多窗口不配套、老用户嫌烦);
  (b) 强制每次先过主页(违背"跳过"需求)。
