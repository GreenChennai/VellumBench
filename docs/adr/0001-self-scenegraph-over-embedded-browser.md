# ADR-0001: 文档渲染用自研场景图,而非嵌入浏览器引擎

- 状态:已接受(源自设计文档 13 篇)
- 背景:需要"编辑 HTML 文档"的能力,最省力的是嵌入 Chromium。
- 候选:A) CEF/Chromium 嵌入;B) Servo;C) Blitz(wgpu+Stylo+Taffy);**D) 自研场景图 + CSS 白名单**
- 决策:**D**(辅以 Chromium 旁路做真值校对与导出)
- 理由:A 200MB+ 体积、进程间合成复杂、无法做 AI 式手柄/锚点高频覆盖层;B/C CSS 覆盖不足且仍是"另一个浏览器的行为";D 让文档模型成为一等公民,可精确控制 round-trip、可无损序列化、可被 Agent 寻址。
- 后果:必须长期投入 CSS 白名单扩展;自绘与浏览器的不一致用**冻结块 + 校对视图**显式化、可测量。
