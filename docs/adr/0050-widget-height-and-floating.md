# ADR-0050: 控件高度体系(派生制)与浮动面板(默认停靠 + 窄窗强制折叠)

- 状态:**已裁定并部分落地**(高度派生制 R0 全落;折叠规则 R0 落纯函数+单测、接线 R2;布局持久化 v3 R2)
- 归属:22 篇 §3.4 两项裁决的正式落档;§5 硬骨头 #23(R0);裁决二后半对应硬骨头 #10(R2 批 6)
- 悬案来源:sable 02 分册 §3.4 —— sable 现行约定(控件高 22/26/32 固定档)与 VellumBench 实证结论(固定档随字号/DPI/界面缩放翻车,CJK galley 高 ≈ 字号×1.4–1.5,写死小行高压叠)冲突

## 1. 裁决一 · 控件高度 = 派生制(硬骨头 #23,R0 落地)

**一切承载文字的控件高度走派生函数,禁止写死小行高:**

```text
row_height(font_size) = max( ⌈font_size × 1.45⌉ + 8, 24 )
```

- **1.45 = CJK galley 系数**:一行 CJK 文字的实际排版(galley)高 ≈ 字号 × 1.4–1.5
  (旧宿主 vb_ui/theme.rs `row_height()` 实测口径,sable 02 §3.4 在案),两上游合并取 1.45;
- **+8 = 呼吸空间**(行高 + 8,与旧宿主同口径);
- **下限 24**:小字号也不许塌,CJK 最小可读高度;
- **向上取整**:高度永远是整像素,亚像素行高在 GPUI 布局里产生抖动。

四档字号实测值(`vb_kit::tokens::font_size`):CAPTION 11 → 24,LABEL 12 → 26,BODY 13 → 27,TITLE 15 → 30。

**名义档 22/26/32 保留**(`vb_kit::tokens::nominal_height::CONTROL_SM/MD/LG`)——sable 约定的保留项,
**仅供无文字控件**(纯图标钮/分隔条/图标轨道):不承载 galley,CJK 压叠不适用;承载文字的控件
引用名义档即违裁决。JSON `layout.row-height.*`(24)镜像常量同口径降级为"无文字占位场景"。

**落地与门禁**:

- 实现:`vb_kit::tokens::row_height()`(常量 `CJK_GALLEY_FACTOR`/`ROW_HEIGHT_PADDING`/`ROW_HEIGHT_MIN` 同处);
- 消费:capabilities_panel 行高已从 `layout::ROW_HEIGHT_LIST`(24 名义值)改为 `row_height(font_size::LABEL)`(26);
- 门禁:`tokens.rs` 单测锁公式(四档值/下限/取整/单调性/名义档保留)——即 22 篇 G-UI8 的"高度派生公式断言"半边;
  字号或公式变更时单测先红,防止"顺手改个数"绕过裁决;
- R2 起 29+ 面板批量消费,组件层(按钮/输入框)封装进 vb_kit 控件时强制走本函数,不再逐处手写。

**备选与不取的理由**:① 名义档扩容(22/26/32 + 更高档位)——不解决缩放/DPI 适应性,正是被实证推翻的路;
② 运行时实测 galley(按当前字体度量)——最准但需要字体栈就绪后的动态度量接口,GPUI 侧 R0 无此出口,
1.45 常数是实测口径的静态近似;若 R1 真文本管线(ADR-0047 路线)给出度量 API,可升级为运行时实测,常数只做回退。

## 2. 裁决二 · 浮动面板 = 默认停靠 + 可浮动 + 窄窗强制折叠

翻 14 篇 F8(当年允许自由浮动导致面板级联遮挡)。裁定:

1. **默认全部停靠**(docked):面板出生即在面板坞/边坞内,不出现无主浮窗(对齐 ADR-0024/0036 的"默认停靠、禁止级联遮挡");
2. **允许拖出为浮动窗**:用 gpui-component DockArea 原生浮动能力,不自研窗口管理;
3. **窄窗 < 1200px 强制折叠为 40px 图标条**:旧宿主 `vb_ui/dock.rs` 规则表语义在新宿主原样保留并复测——

   | 窗口宽度 | 用户折叠偏好 | 结果 |
   |---|---|---|
   | < 1200 | 任意 | **强制折叠**(40px 图标条,无横向滚动条) |
   | ≥ 1200 | 未折叠 | 展开 |
   | ≥ 1200 | 折叠 | 折叠(用户折的尊重) |

   手动展开**不能**覆盖 <1200 强制折叠;窄窗下图标条点击只切 Tab 不展开;强制折叠不回写用户偏好
   (窗口拉宽后自动恢复展开,不需要用户再点一次)。常量单一真相 = `vb_kit::tokens::layout`
   (`COLLAPSE_BELOW` 1200 / `RIGHT_DOCK_COLLAPSED` 40 / 拖拽钳制 240–420)。

**R0 落地口径(诚实声明)**:

- 已落(R0 本批):规则纯函数 + 规则表单测,`vb_shell::dock_rules`
  (`should_collapse` / `rail_click_can_expand` / `clamp_width` / `ICON_RAIL_WIDTH` 再导出)。
  实现成本低(纯函数无宿主依赖),按"规则只写一份"纪律先落并锁测;
- 未落(记 **R2 面板批次首项**):把规则接进 gpui-component DockArea 事件流 ——
  窗口 resize 监听 → 折叠态切换、图标条点击拦截(只切 Tab)。这需要动 sable dock 交互面
  (订阅窗口 resize + 干预 DockItem 展开),成本不在"规则"而在"接线",R0 无面板可折,接了也没对象;
- 布局持久化(DockAreaState + workspace.json **v3**,带 v2 迁移与坏文件回退默认)= R2 批 6(硬骨头 #10),
  本 ADR 不重复立项。

## 3. 后果

- 正面:字号/界面缩放/DPI 变化时文字控件高度自适应,CJK 压叠结构性消除;两上游(sable 固定档经验
  与 VellumBench 实证)合并为单一裁决,sable 侧悬案有案可稽;折叠规则先落纯函数,R2 接线时零规则歧义。
- 代价:1.45 是静态近似,特殊字体(超大字号/异常 fallback)可能偏差 ±1px——由"向上取整 + 下限"兜底;
  名义档与派生制并存,存在误用名义档于文字控件的可能,由 R2 组件封装(唯一入口)与代码评审防守。
- 回顾锚点:R2 面板批次结束时回看本 ADR——折叠接线是否落地、派生制是否有旁路(手写行高)需要复查。
