# 06 · 工具集与编辑能力规格

> 每个工具 = 一个状态机。本篇定义"按下去会发生什么"，不定义如何渲染（见 05 篇）。

---

## 一、工具接口

```rust
pub trait Tool {
    fn id(&self) -> ToolId;
    fn cursor(&self, ctx: &ToolCtx) -> CursorIcon;
    fn on_pointer_down(&mut self, ctx: &mut ToolCtx, e: PointerEvent) -> ToolSignal;
    fn on_pointer_move(&mut self, ctx: &mut ToolCtx, e: PointerEvent) -> ToolSignal;
    fn on_pointer_up(&mut self, ctx: &mut ToolCtx, e: PointerEvent) -> ToolSignal;
    fn on_key(&mut self, ctx: &mut ToolCtx, k: KeyEvent) -> ToolSignal;
    fn draw_overlay(&self, ctx: &ToolCtx, ov: &mut OverlayCanvas); // 拖动数值浮层等
    fn control_panel(&self) -> ControlPanelSpec;                   // 控制面板字段
}
// ToolSignal::{None, Commit(Command), Preview(Command), Cancel, SwitchTool(ToolId)}
```

**关键约束**：工具只能产出 `Command`（可逆命令），**不得直接改 Document**（见 09 篇）。拖动过程中的 `Preview` 命令不入 undo 栈，仅在 `up` 时 `Commit` 一次。

## 二、工具清单与优先级

| 优先级 | 工具 |
|---|---|
| **P0（v0.1–v0.3）** | 选择、直接选择、编组选择、矩形、椭圆、直线、钢笔、文字、抓手、缩放、画板、吸管、渐变 |
| **P1（v0.4–v0.5）** | 铅笔/平滑、曲率、形状生成器、路径橡皮、旋转/镜像/缩放/倾斜/自由变换、切片、剪刀、美工刀 |
| **P2（v0.6+）** | 画笔（压感）、斑点画笔、宽度工具、混合、封套变形、符号（v2） |
| **不做（明确提示）** | 实时上色组、网格工具、透视网格、图像描摹、3D、图表、闪光、缠绕 |

> **不支持工具的处理**：默认在工具箱中隐藏（保持工具栏整洁）；`设置 → 工具 → 显示未支持工具` 可开启，显示为置灰图标，点击弹出"计划于 vX 支持"提示。**绝不能点了没反应。**

## 三、各工具行为规格

### 3.1 选择工具 `V`

| 操作 | 行为 |
|---|---|
| 单击对象 | 选中（多重叠时选最上层）；`Mod+单击` 穿透到下一层 |
| `Shift+单击` | 加选 / 减选 |
| 单击空白拖框 | 框选（**相交即选中**） |
| 拖动对象 | 移动；中途 `Alt`=复制，`Shift`=约束，`Space`=同时平移视图，`Esc`=取消回原位 |
| 双击编组 | 进入隔离模式 |
| 拖动到画板外 | 允许（AI 行为），画板外内容变暗显示 |
| 拖动跨画板 | 坐标自动换算到目标画板 |

**数值浮层**（拖动时跟随光标）：`X: 120  Y: 80  ΔX: +12  ΔY: -4  W  H`（AI 行为，必须做）。

### 3.2 直接选择工具 `A`

- 单击路径 → 显示该路径全部锚点（空心）
- 单击锚点 → 选中（实心）；`Shift` 多选；框选锚点
- 拖动锚点/手柄；`Alt+拖手柄` 单侧独立；`Alt+点击锚点`（钢笔态）转换角点
- 选中锚点 `Delete` → 删除并重连路径
- 拖动路径段（`Mod+拖动`）→ 移动整段并保持连接

### 3.3 矩形 `M` / 椭圆 `L` / 直线 `\`

| 操作 | 行为 |
|---|---|
| 单击 | 打开对话框输入尺寸（与 AI 一致） |
| 拖动 | 创建；`Shift`=正方形/正圆；`Alt`=从中心；`Alt+Shift`=从中心的正形 |
| 拖动中 `↑/↓` | 调整圆角（矩形，AI 行为）⭐ |
| 拖动中 `Space` | 移动绘制起点 |
| 拖动中 `C` | 切换"从中心绘制" |
| 拖动中 `F` | 切换"绘制方向" |
| 拖动中 `[` / `]` | 减小 / 增大圆角 |

### 3.4 钢笔 `P`

（详见 02 篇 5.3）

补充：
- 拖动中 `Esc` = 删除最后一段
- 悬停已存在路径 → 显示 `+`（添加锚点）；悬停锚点 → `-`（删除）
- 起点显示小圆圈表示可闭合

### 3.5 曲率工具（v0.4）

点击落点自动生成平滑曲线（AI CC 2018+ 行为）：无需拖手柄，点击后曲线自动拟合，可再拖动点调整。

### 3.6 文字 `T`

| 操作 | 行为 |
|---|---|
| 单击 | 点文本（宽度随内容增长） |
| 拖框 | 区域文本（定宽，自动换行）；框可后续改尺寸 |
| `Shift+T` | 在点/区域/路径文本间循环 |
| 单击路径（v1.5） | 路径文本（SVG `textPath`） |
| 双击对象 | 进入编辑 |
| `Esc` / `Mod+Enter` | 提交；`Esc` 二次 = 放弃 |
| 区域文本溢出 | 右下角红点；双击角点自动扩高（AI 行为） |

**文本能力清单**：字体/字号/字重/斜体、行距、字偶距/字距、水平/垂直缩放、基线偏移、字符旋转、下划线/删除线、大小写、上/下标、语言、抗锯齿（→ `-webkit-font-smoothing`）；段落：9 种对齐、左右缩进、首行缩进、段前段后、避头尾（CJK）、连字、标点挤压。

### 3.7 铅笔 `N` / 平滑

- 拖动自由绘制，自动拟合为贝塞尔（保真度参数：0–20px，设置项）
- 绘制中 `Alt` = 平滑工具（抹平抖动）
- 闭合：终点接近起点自动闭合（可关）
- 绘制完成后自动选中，可用直接选择微调

### 3.8 形状生成器 `Shift+M`（v1.5）

按住拖动划过多个重叠形状 → 合并/删除区域。**依赖路径布尔运算**（见 3.9）。

### 3.9 路径查找器（依赖技术验证）

10 种运算：**联集 / 减去顶层 / 交集 / 差集**（基本）+ **分割 / 修边 / 合并 / 裁剪 / 轮廓 / 减去后方对象**（扩展）。

> ⚠️ **需要 spike（1–2 天）**：kurbo 本身不含布尔运算。候选：
> 1. `flo_curves`（纯 Rust，有 path 布尔与 offset）— 首选
> 2. `skia-safe` 仅用其 `Path::op` 几何能力（成熟但引入 30MB+ 依赖、构建重）
> 3. `vello_cpu` 光栅 + marching squares 矢量化（质量差，兜底）
>
> **决策点**：spike 后锁定方案并写进 13 篇 ADR。若 v1 前无法稳定，则路径查找器降级为"仅对同色同描边形状提供合并/裁剪"，其余置灰。

### 3.10 变换工具族

| 工具 | 行为 |
|---|---|
| 旋转 `R` | 单击设中心 → 拖动旋转；`Shift` 约束 15°；`Alt` 复制旋转 |
| 镜像 `O` | 同上，拖动决定镜像轴 |
| 缩放 `S` | 同上；`Shift` 等比；`Alt` 从中心 |
| 倾斜 | `Mod+拖角手柄`（选择工具下） |
| 自由变换 `E` | 四角独立拖动（透视变形不做，网页无对应） |
| 再次变换 `Mod+D` | 重复上次变换（位移/缩放/旋转）⭐ 灵魂功能 |
| 分别变换 | 对每个选中对象独立应用变换（可加随机抖动） |
| 重置定界框 | 清除旋转使定界框水平 |

**变换面板**：`☑ 缩放描边和效果`（AI 有，必须做）、`☑ 对齐像素网格`。

### 3.11 渐变 `G`

- 画布内渐变批注者：拖动起点/终点/中点，直接改渐变方向与长度
- 拖动中 `Alt` 复制；`Shift` 约束 45°
- 色标在渐变面板编辑；双击批注者上的色标改色
- 类型：线性 / 径向 / 角度（conic，v2）

### 3.12 吸管 `I`

- 点击吸取：填充/描边/文字属性（按设置决定吸取范围）
- `Alt+点击` = 吸取**全部**属性并应用到当前选中对象
- `Shift+点击` = 只吸取颜色到当前激活的填充/描边

### 3.13 画板 `Shift+O`

| 操作 | 行为 |
|---|---|
| 拖框 | 新建画板 |
| 拖动画板 | 移动（含内部内容） |
| 拖动角/边 | 改尺寸（内容默认**不**缩放，可设"缩放内容"） |
| 双击画板名 | 重命名 |
| 画板选项（控制面板） | 预设（Web/A4/自定义）、取向、背景色、**画板内边距**、设为默认 |
| 画板菜单（右上角 ⋮） | 导出此画板、复制、删除、重新排列（网格/按行/按列）、适配图稿边界 |
| 画板导航（状态栏 ◀ ▶） | 前后画板跳转 |

### 3.14 切片 `Shift+K`

拖框建立切片 → `data-vb-slice="name"` + 导出预设；切片可"从选区创建"（`对象 → 切片 → 建立`）。

## 四、跨工具的通用能力

### 4.1 智能参考线（Smart Guides）⭐ 决定"像不像"

| 类型 | 触发 |
|---|---|
| 对齐 | 对象边/中心/锚点 与 其他对象或画板的 边/中心 对齐时 |
| 间距 | 与其他对象形成等距时，显示间距数值与双向箭头 |
| 角度 | 旋转接近 0/45/90/180/270 或与其他路径平行/垂直时 |
| 尺寸相等 | 拖动的尺寸与其他对象宽/高一致时 |
| 画板中心 | 与画板水平/垂直中心对齐时 |

**规格**：
- 颜色品红 `#FF00FF`，1px 虚线；标签文字 11px，深底品红字
- 吸附阈值：**屏幕空间 6px**（不随缩放变化，这是正确做法）
- 吸附目标优先级：画板 > 最近对象 > 网格
- 拖动时按住 `Mod` **临时禁用**吸附（AI 行为）
- 开关：`Mod+Shift+;`（AI 行为）+ 设置项

### 4.2 吸附体系

| 吸附到 | 设置项 | 默认 |
|---|---|---|
| 网格 | 对齐网格 `Mod+Shift+'` | 关 |
| 像素网格 | 对齐像素 | 开（网页场景重要） |
| 智能参考线 | 智能参考线 | 开 |
| 画板边界 | — | 开 |
| 路径锚点 | — | 开 |

### 4.3 隔离模式

- 双击编组/剪切组进入；`Esc` 或点击面包屑「◀ 上一层」退出
- 进入后：其余对象淡化（默认 25% 不透明度）且不可选
- 顶部显示面包屑：`文档 › 内容 › Hero 编组`
- 隔离态下新建对象自动进入该编组
- `Shift+双击` = 在新窗口隔离（v2）

### 4.4 蒙版

| 类型 | 建立 | 释放 |
|---|---|---|
| 剪切蒙版 | `Mod+7` | `Mod+Alt+7` |
| 不透明度蒙版 | 透明度面板 → 制作蒙版 | 释放 |
| 容器内裁剪 | 拖入容器自动（可选行为） | 拖出 |

映射到 `overflow:hidden` / `clip-path` / `mask-image`（见 01 篇 2.3）。

### 4.5 编组与层级

`Mod+G` / `Mod+Shift+G` / `Mod+[` `Mod+]` `Mod+Shift+[` `Mod+Shift+]`；锁定 `Mod+2`、隐藏 `Mod+3`；**图层面板拖拽**重排。

### 4.6 效果（Effect）

| AI 效果 | CSS 映射 |
|---|---|
| 投影 Drop Shadow | `box-shadow: X Y blur spread color` |
| 内阴影 Inner Shadow | `box-shadow: inset …` |
| 外发光 Outer Glow | `box-shadow: 0 0 blur color` 多层 |
| 内发光 | `box-shadow: inset 0 0 blur color` |
| 高斯模糊 | `filter: blur(Npx)`（作用于对象 → `filter`；作用于投影 → `drop-shadow`） |
| 圆角 Rounded Corners | `border-radius`（对路径无效 → 提示"仅对盒对象有效"） |
| 羽化 | `mask-image: radial-gradient(...)` 近似 |
| 扭曲/变换 | `transform` 系列 |
| SVG 滤镜 | 保留原样，冻结 |

**效果面板**可添加多个效果、调整顺序、临时禁用（眼睛）—— 与 AI 一致。

### 4.7 栅格化 / 分辨率

`对象 → 栅格化`：把矢量/文本转为 PNG（写入 `assets/`），可选分辨率 72/150/300 ppi。用于"不支持的效果"的最后兜底。

## 五、图像能力

| 能力 | 说明 |
|---|---|
| 置入 | 拖入或 `文件 → 置入`；默认**引用**（`src="assets/x.png"`），可选嵌入 base64 |
| 替换 | 右键 → 替换图像（保持尺寸与蒙版） |
| 裁剪 | 用剪切蒙版 / `object-fit: cover` + 容器 |
| 描边/效果 | 同盒对象 |
| 缺失资源 | 画布显示红框 + 图层面板警告；`文件 → 查找缺失资源` |
| 分辨率 | 显示原始尺寸与实际显示尺寸（信息面板） |

## 六、编辑态辅助

| 功能 | 说明 |
|---|---|
| 轮廓模式 `Mod+Y` | 只画线框与锚点，不画填充（排查重叠对象） |
| 叠印预览 | 网页无对应 → 隐藏该项（不显示禁用图标） |
| 像素预览 | 把文档按 1:1 设备像素光栅显示 |
| 标尺 `Mod+R` | 从标尺拖出参考线；`Mod+5` 从对象生成参考线；`Mod+Alt+;` 锁定 |
| 网格 `Mod+'` | 8px/64px 主次网格；`Mod+Shift+'` 对齐网格 |
| 度量工具 | 拖动测量距离并在信息面板显示 |
| 隐藏边缘 `Mod+Shift+H` | 隐藏选中对象的边界框 |
| 显示/隐藏画板边缘 | 画板描边 |

## 七、明确不支持（点击时给提示而非沉默）

| AI 功能 | 提示文案 |
|---|---|
| 实时上色 | 「实时上色在 v1 不支持；可用路径查找器或形状生成器代替」 |
| 网格工具 | 「渐变网格无 HTML 对应；建议用多层径向渐变叠加模拟」 |
| 图像描摹 | 「图像描摹暂不支持」 |
| 3D / 透视 | 「3D 与透视网格不支持」 |
| 符号工具 | 「符号将于 v2 以『组件』形式提供」 |
| 变量（AI 的 Variables） | 「变量在 v0.7 以『设计令牌』提供」 |
