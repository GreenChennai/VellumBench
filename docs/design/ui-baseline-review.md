## 1 · 基线重刷记录(诚实口径)

| 项 | 结果 |
|---|---|
| 尝试命令 | `powershell -File tools/ui_shots.ps1 -Generate -Scale 1.0 -Theme dark` / `-Theme light`(各 5 场景) |
| 修复的脚本缺陷 | `FindMainWindow` 的「宽 > 400」判定会先命中控制台子系统的宿主控制台窗(~986×527),抢在 wgpu 初始化完成的 GUI 窗之前 —— 基线被拍成黑屏控制台。已改为「宽 > 900 且高 > 560」双重过滤(`tools/ui_shots.ps1`,2026-10-05) |
| 本机会话限制 | 修复后窗口命中正确(标题栏可拍),但**客户区恒为黑**:`CopyFromScreen` 报「句柄无效」—— 本工作会话无交互桌面 GDI/DWM 合成面,swapchain 呈现内容无法进入任何抓图路径(PrintWindow / 屏幕拷贝均黑) |
| 处置 | ① 库内基线**保留上一可用版**(S3 时代,像素与当前分支有差,见 §2);② 不提交黑屏图冒充基线;③ **像素级重刷需在交互桌面会话执行**(作者机命令同上,5 场景 × 深浅两主题 ≈ 2 分钟) |
| 判定 | G-UI-G 的「基线重刷」在本环境**部分完成**(脚本缺陷修复 + 限制记录 + 设计走查);像素刷新待有桌面的会话 |
