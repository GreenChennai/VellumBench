| 投入模式 | 预计周期 |

| 业余（每周 10–15h）+ Agent 辅助 | **12–18 个月** |

## S0 · 技术验证（Spike）1–2 周 ★最高优先级

**在写任何产品代码之前**，先做 6 个小实验，每个半天到一天，结论写进 13 篇 ADR：

| # | Spike | 验证什么 | 失败预案 |
|---|---|---|---|
| 1 | wgpu + Vello 窗口 | Vulkan 后端能否在 RX 9070 GRE 起；1 万矩形帧率 | 换 GL/DX12；评估 Skia |
| 2 | Vello 并行编码 | `SceneFragment` 并行是否真的提速 | 单线程编码（仍可接受） |
| 3 | Parley + Swash + 中文 | 中文整形/换行/图集是否正常，性能如何 | 回退 `fontdue` CPU 光栅 |
| 4 | 保真 HTML 解析 | `html5ever` 能否保留注释/未知属性/原始顺序 | 改用 `scraper` + 手写序列化 |
| 5 | 路径布尔 | `flo_curves` 能否满足路径查找器 | 见 06 篇 3.9（skia-safe / 降级） |
| 6 | Taffy 布局 | absolute + flex 混合是否够用 | 自研简化布局 |

**产出**：6 个最小可运行 demo（各自独立仓库目录 `spikes/`）+ 结论文档 + 技术栈锁定。
**门禁**：Spike 1 必须达到 1 万矩形 ≥ 60fps，否则重新评估渲染选型。

## v0.1 · 骨架（2–3 周）

**目标**：窗口能开、Vulkan 能画、矩形能拖、能存能导出 PNG。

| 模块 | 内容 |
|---|---|
| 工程 | workspace + crate 骨架、`vb_common`（几何/颜色/单位/StableId） |
| 渲染 | wgpu(Vulkan) + Vello 初始化、正交相机、平移/缩放、网格背景、`Space` 抓手、`Alt+滚轮` 缩放 |
| 文档 | 最小 `Document`（只支持 `Box` 节点）、Arena、StableId |
| 交互 | 选择工具：点选、框选、拖动、Shift 约束、Alt 复制、**拖动数值浮层** |
| 创建 | 矩形工具（拖动创建 + `Shift` 正方 + 拖动中 `↑↓` 调圆角） |
| UI | egui 面板占位（属性面板最小版：X/Y/W/H/填充色）；状态栏（缩放/坐标） |
| 持久化 | `.vbdoc` 最小读写；导出 `index.html`（单文件内联） |
| 命令 | `Command` trait + Undo/Redo（`Mod+Z` / `Mod+Shift+Z`） |
| 性能 | 内置性能面板（FPS/帧时间） |

**不做**：文本、图片、图层面板、钢笔、画板（只有 1 个默认画板）、渐变、导出除 PNG 外。

**60 秒演示脚本**：
```
启动 → 画 3 个矩形 → 拖动/Alt 复制 → 改颜色与圆角 → Ctrl+Z 撤销 → 
导出 index.html → 浏览器打开（视觉一致）→ 导出 PNG
```

**验收**：
- [ ] 冷启动 ≤ 2s（v0.1 放宽，v0.9 收紧到 1.5s）
- [ ] 3000 矩形拖动 ≥ 60fps
- [ ] 撤销/重做全部正确
- [ ] 导出 HTML 能被浏览器正确打开且与画布一致（肉眼 + 像素比对）
- [ ] 性能面板数字可信

| 命令 | 编组/解组/层序/锁定/隐藏；Undo 合并策略 |
| 持久化 | 自动保存 + 崩溃恢复 |

**验收**：
- [ ] round-trip 语料（先 20 个）：L0 100%、L1 100%

- [ ] 导入一个 Bootstrap 简单页面 → 大部分可编辑、不支持的进 `unknown` 不丢失
