# 02 · 交互与快捷键规范

> 目标：**让 AI 老用户不需要看文档**。
> 实现优先级：先做全快捷键映射表（一个 keymap JSON），再做工具行为。任何交互争议，以"AI CC 2024 Windows 默认键位"为准。

---

## 一、输入约定

| 项 | 约定 |
|---|---|
| 主修饰键 | `Ctrl`(Win) / `Cmd`(macOS) 统一记为 **Mod**；`Alt` = Option；`Shift` 不变 |
| 鼠标 | 左键主操作；右键上下文菜单；中键拖动平移（可关）；滚轮默认滚动，`Alt+滚轮` 缩放 |
| 触控板 | 双指平移；捏合缩放（映射为缩放，非 DPI 缩放） |
| 数位板 | 压感接入画笔/铅笔/宽度工具（v1 可选，接口先留） |
| 键位方案 | 可切换：`AI 默认` / `AI 兼容（避开系统键）` / `自定义`，存 `keymap.json` |
| 输入延迟 | 按键 → 画面反馈 ≤ 16ms；拖动时启用"预测渲染"（先变换低精度层，静止后精修） |

**输入上下文栈**（避免误触发，从高到低）：
```
文本编辑态 > 面板/输入框聚焦 > 工具活动态（钢笔绘制中/变换中） > 全局
```
只有栈顶上下文消费按键。文本编辑态下，除 `Esc`/`Mod+Enter` 外不触发任何工具快捷键。

## 二、修饰键语义（AI 的四大灵魂手势，必须完全一致）

| 手势 | 行为 | 备注 |
|---|---|---|
| **Alt + 拖动对象** | 复制并拖动 | AI 招牌 |
| **Shift + 拖动对象** | 约束方向（水平/垂直/45°）或等比 | |
| **Alt + Shift + 拖动** | 约束 + 复制 | |
| **Space + 拖动对象（拖动中按下）** | 边拖边平移画布 | ⚠️ AI 独有，很多人不知道但一用就回不去 |
| **Alt + 拖动缩放手柄** | 以中心为基准缩放 | |
| **Shift + 拖动缩放手柄** | 等比缩放 | |
| **Alt + 点击** | （工具相关）钢笔：转换锚点；吸管：取到所有属性 | |
| **Mod + 点击** | 穿透选择：选中下一层对象 | |
| **Mod + 拖动（直接选择下）** | 临时切换为选择工具 | |
| **双击编组** | 进入隔离模式 | |
| **双击对象（已在编组内）** | 再深入一层 | |
| **Esc** | 退出隔离 / 取消当前绘制 / 取消文本编辑 | |
| **拖动中按 Esc** | 取消本次拖动，对象回原位（AI 行为） | |

## 四、菜单命令快捷键

### 文件

| 键 | 命令 | 键 | 命令 |
|---|---|---|---|
| `Mod+N` | 新建 | `Mod+Shift+S` | 另存为 |
| `Mod+O` | 打开（`.vbdoc` 或 `index.html`） | `Mod+Alt+S` | 存储副本 |
| `Mod+W` | 关闭 | `Mod+E` | **导出…**（AI 无默认，本方案自定义） |
| `Mod+S` | 存储（同时刷新 HTML 输出） | `Mod+Shift+E` | 上一导出（快速重复导出） |
| `Mod+P` | 打印 | `Mod+Alt+E` | 导出为屏幕所用格式（画板批量） |

### 编辑

| 键 | 命令 | 键 | 命令 |
|---|---|---|---|
| `Mod+Z` | 撤销 | `Mod+F` | 贴在前面 |
| `Mod+Shift+Z` | 重做 | `Mod+B` | 贴在后面 |
| `Mod+X/C/V` | 剪切/复制/粘贴 | `Mod+Shift+V` | 就地粘贴 |
| `Mod+Shift+C` | ⚠️ AI 中是**水平居中对齐**（非复制样式） | `Mod+Alt+Shift+V` | 在所有画板上就地粘贴 |
| `Mod+D` | **再次变换**（Transform Again）⭐ | `Mod+A` | 全选 |
| `Mod+Alt+D` | 分别变换 ⚠️待实测 | `Mod+Shift+A` | 取消全选 |
| `Delete` / `Backspace` | 删除 | `Mod+Alt+A` | 选择当前画板上全部对象 |

### 对象

| 键 | 命令 | 键 | 命令 |
|---|---|---|---|
| `Mod+G` | 编组 | `Mod+]` | 前移一层 |
| `Mod+Shift+G` | 取消编组 | `Mod+[` | 后移一层 |
| `Mod+7` | 创建剪切蒙版 | `Mod+Shift+]` | 置于顶层 |
| `Mod+Alt+7` | 释放剪切蒙版 | `Mod+Shift+[` | 置于底层 |
| `Mod+8` | 建立复合路径 | `Mod+2` | 锁定 |
| `Mod+Alt+8` | 释放复合路径 | `Mod+Alt+2` | 解锁全部 |
| `Mod+J` | 连接路径 | `Mod+3` | 隐藏 |
| `Mod+Alt+J` | 平均路径 ⚠️待实测 | `Mod+Alt+3` | 显示全部 |
| `Mod+Shift+O` | 创建轮廓（文字转曲） | `Mod+B`*(冲突)* | 混合建立（文本态下为贴在后面） |

> `Mod+B` 冲突处理：**文本编辑态**=贴在后面；**选择态**=混合建立。与 AI 一致（AI 也这么处理）。

## 五、键鼠细节行为（决定"像不像"的最后一公里）

### 5.1 选择工具

- 单击选中；`Shift+单击` 加选/减选；`Mod+单击` 穿透到下一层
- 框选（拖动出矩形）：**触及即选中**（与 AI 一致，不是"完全包含"）
- 拖动未选中对象：直接拖动（不需先选中）—— AI 行为
- 拖动前按下 `Alt` 复制；拖动中按 `Alt` **也可以**复制（AI 支持中途按下）
- 拖动中按 `Shift` 锁定轴向
- 拖动中按 `Space` 平移画布

### 5.2 直接选择工具

- 单击路径显示所有锚点；单击锚点选中（实心=选中，空心=未选）
- 框选锚点；`Shift+单击` 多选
- 拖动锚点移动；拖动手柄调曲率；`Alt+拖手柄` = 单侧独立
- 选中锚点后 `Delete` 删除锚点（路径自动重连）
- 拖动路径段（`Mod+拖动`）移动整段

### 5.3 钢笔工具

| 操作 | 行为 |
|---|---|
| 单击 | 放置角点 |
| 单击并拖动 | 放置平滑点并拉出对称手柄 |
| `Alt+拖手柄` | 打断手柄，单侧调整 |
| `Alt+悬停锚点` | 光标变转换点工具，点击转换为角点 |
| 拖锚点 | 移动锚点 |
| `Mod` | 临时切换为直接选择（可移动已放置的锚点） |
| 回到起点单击 | 闭合路径 |
| `Enter` / `Esc` / 切工具 | 结束当前路径（保持选中） |
| `Shift` | 约束 45°/水平/垂直 |
| 悬停在路径上 | 显示"+"号 = 添加锚点；悬停锚点显示"-" = 删除 |

### 5.4 变换手柄（AI 的 8 个手柄 + 4 个角标）

- 8 个缩放手柄：角手柄默认等比（AI 行为），边手柄单轴；`Shift` 反转该行为
- 手柄外悬停 → 旋转光标（`Shift` 约束 15°）
- `Mod+拖动角手柄` = 倾斜（AI 行为）
- `Alt` = 从中心变换
- **变换时显示实时数值**：W/H/ΔX/ΔY/角度（AI 的信息浮层，必须做）

### 5.5 文本

- `T` 单击 = 点文本（宽度随内容）；`T` 拖动 = 区域文本（定宽，自动换行）
- 双击文本对象 = 进入编辑
- 三击 = 选整段；四击 = 选全部
- `Esc` / `Mod+Enter` = 提交并退出；`Esc` 两次 = 放弃修改
- 拖出文本框外 = 溢出标记（红色小方块，与 AI 一致）

### 5.6 视图导航

| 操作 | 行为 |
|---|---|
| `Space+拖` | 抓手平移 |
| `Alt+滚轮` | 以光标为中心缩放（默认） |
| `Ctrl+滚轮` | 缩放（备用，设置里切换"缩放修饰键"） |
| 无修饰滚轮 | 垂直滚动；`Shift+滚轮` 水平滚动 |
| 捏合手势 | 以双指中心缩放 |
| `Z+点击` / `Z+拖框` | 放大 / 放大到区域 |
| `Mod+0` | 适应窗口（含所有画板） |
| 双击抓手 | 适合窗口 |
| 双击缩放工具 | 100% |

### 5.7 拖放

- 拖入图片文件 → 置入为图像对象（保持比例，按 `Shift` 填充框）
- 拖入 `.svg` → 置入为矢量路径（可编辑）
- 拖入 `.html` → 导入为文档 / 冻结块
- 拖入文本 → 创建点文本

## 六、与 AI 的差异（必须显式告知用户）

| 场景 | AI | Vellum Bench | 原因 |
|---|---|---|---|
| 画板外内容 | 可存在但不可见 | 画板外内容**可见但变暗**（可关） | 网页里画板外无意义，需提示 |
| 导出 | 导出为屏幕所用格式 | 同 + 浏览器真值校对 | |
| 画板滚动 | 无 | 画板高度 > 视口时可滚动 | 网页是长文档 |
| 链接 | 无 | 属性面板可设 `href` | HTML 能力 |
| 撤销历史 | 200 步 | 无限（命令模式，磁盘溢出） | |

## 七、快捷键实现规范

```
keymap.json 结构
{
  "scheme": "illustrator-win",
  "contexts": {
    "global":   { "Mod+S": "file.save", "Mod+0": "view.fit", ... },
    "tool.pen": { "Escape": "pen.finish", "Alt": "pen.convertAnchor" },
    "text.edit":{ "Escape": "text.commit", "Mod+Enter": "text.commit" },
    "panel":    { "Escape": "focus.canvas" }
  },
  "tools": { "V": "tool.select", "A": "tool.directSelect", ... }
}
```

**实现要点**：
1. 所有菜单项、工具、面板按钮都绑定**命令 ID**（如 `object.group`），不是直接绑函数 → 快捷键、菜单、面板、Agent CLI、宏共用一套命令表（与 09 篇的命令模式天然契合）。
2. 命令表是**单一真相**：`commands.yaml` 定义 id / 名称 / 默认键位 / 所属菜单 / 是否可撤销 / 是否暴露给 Agent。
3. 键位冲突在启动时自检，冲突项报 warning 并禁用后来的绑定。
4. 提供「按键速查表」面板（`Mod+/`），支持反查：按了什么键 → 当前绑定什么命令。
5. 提供「学习模式」（可选）：使用菜单命令时，气泡提示对应快捷键——帮助从 AI 之外的软件迁移来的用户。
