# 03 · 界面布局与面板规范

> AI 的界面布局是经过 30 年验证的工具布局。原则：**不重新发明，只做必要加法**。
> 所有尺寸单位 px（@1x），支持 100%/125%/150% 系统缩放。

---

| 区域 | 默认尺寸 | 说明 |

| 最小窗口 | 1024×640 | < 1200 自动折叠右侧为图标条 |

## 三、控制面板（随工具变化的上下文条）

| 当前工具 | 控制面板显示 |
|---|---|

| 选择（有选区） | 变换：X/Y/W/H/旋转/倾斜、参考点九宫格、对齐画板、填充、描边、不透明度、编组/排列 |

| 钢笔 | 填充/描边/粗细、自动闭合提示 |
| 矩形/椭圆 | 填充/描边/圆角（矩形）/起始角 |

## 四、属性面板（最常改，规格最细）

```
┌─ 属性 ─────────────────────────────────┐
│ [默认 ▾] 状态：默认|悬停|按下|禁用     │  ← AI Plus
│ 标签  [div        ▾]  ⓘ                │  ← 语义标签
├────────────────────────────────────────┤
│ ▸ 变换                                 │
│   X 120   Y 80     W 320   H 180       │
│   ∠ 0°    倾斜 0°   ⬚ 参考点九宫格      │
│   ☑ 缩放描边和效果                      │
├────────────────────────────────────────┤
│ ▸ 外观                                 │
│   填充 [■ #FF5A1F ▾]  100%             │
│   描边 [□ 无      ▾]  2pt  居中 ▾      │
│   效果 [+ 添加效果]  → 投影/模糊/圆角   │
│   不透明度 100%   混合模式 [正常 ▾]     │
├────────────────────────────────────────┤
│ ▸ 布局（自动布局）                      │
│   显示 [块 ▾] 方向[—] 间距 16          │
│   主轴[居中 ▾] 交叉轴[居中 ▾]           │
│   内边距 24  外边距 0                   │
├────────────────────────────────────────┤
│ ▸ 文本（文本对象才显示）                │
│   Inter ▾ 常规 ▾ 48px                  │
│   行距 1.2  字距 0  对齐 [左 ▾]         │
├────────────────────────────────────────┤
│ ▸ 交互  链接 https://…  目标 [_self ▾]  │
│ ▸ 无障碍 alt: …  aria-label: …          │
├────────────────────────────────────────┤
│ ▸ 导出  名称 Hero  预设 @1x @2x @3x     │
└────────────────────────────────────────┘
```

**字段规则**：
- 数值框支持：直接输入、`↑/↓` 步进（1），`Shift+↑/↓` 步进（10），拖动标签（AI 的 scrubby 滑块 ⭐ 必做）、数学表达式输入（`320/2` → 160）
- 颜色框：点击弹出取色器；`Alt+点击` 打开完整颜色选择器；支持 `HEX / RGB / HSL / CSS 变量` 四种输入
- 修改即生效并进入 undo 栈（数值框连续输入合并为一次 undo，避免刷栈）

## 五、右侧面板组规格

### 5.1 图层面板 `F7`

```
┌─ 图层 ─────────────────────┐
│ 🔍 搜索图层名              │
├────────────────────────────┤
│ ▼ 📁 背景          👁 🔒 ●  │  ← 图层：眼睛/锁/目标圆点/颜色块
│   ▼ 📁 编组 1          👁   │
│     ▢ 矩形 1                │
│     ▢ 主标题                │
│   ▢ Hero 图像               │
│ ▼ 📁 内容          👁       │
│   ❄ 冻结块 (不支持的 CSS)   │  ← 雪花图标
├────────────────────────────┤
│ [⊕图层] [⊕子层] [⊕编组] [🗑]│
└────────────────────────────┘
```
- 色块（AI 的图层颜色标记）：选中对象时显示该颜色，对应 AI 的图层着色
- 拖拽重排（含跨图层），拖到编组上高亮表示进入编组
- `Alt+拖拽` = 复制
- 双击名称 = 重命名（就地编辑）
- 右键菜单：隔离、锁定其他、隐藏其他、选择同类、导出、转换为编组/图层
- 底部：定位对象（🔍 跳转到画布）、建立/释放剪切蒙版

### 5.2 变换面板 `Shift+F8`
W / H（含锁链等比）、X / Y（可切参考点九宫格）、旋转、倾斜；底部复选框：**缩放描边和效果**、**对齐像素网格**、变换图案（v2）。

### 5.3 对齐面板 `Shift+F7`
- 对齐对象 6 按钮：左 / 水平居中 / 右 / 顶 / 垂直居中 / 底
- 分布对象 6 按钮；分布间距 2 按钮
- 「对齐到」下拉：选区 / 关键对象 / 画板
- 「关键对象」：最后选中的对象加粗描边（AI 行为）

### 5.4 颜色面板 `F6`
- 色轮 / 滑块（HSB / RGB / CMYK / **CSS 变量** 页签）
- 取色器、`D` 恢复默认、`X` 切换、`Shift+X` 交换
- ⚠️ 无颜色管理模式（网页即 sRGB），但保留 `色彩配置文件` 只读显示

### 5.5 色板面板
- 网格/列表切换；色板类型：**全局色**（= CSS 变量，`--vb-color-1`）标记左下角白三角 ⭐ AI Plus
- 新建 / 删除 / 复制 / 合并 / 导入 `.ase`（可选）/ 从页面提取（调 WPI 的 `color_profiler`）

### 5.6 渐变面板 `Ctrl+F9`
类型（线性/径向/角度 `conic`）、角度/长宽比、色标条（拖动/双击改色/下方输入位置）、不透明度标、反向、中点菱形。

### 5.7 描边面板 `Ctrl+F10`
粗细、端点（平头/圆头/投射末端）、边角（斜接/圆角/斜切）、斜接限制、虚线（虚线值/间隙，最多 6 组）、对齐（居中/内侧/外侧）、箭头（起/止，矢量路径）。

### 5.8 透明度面板 `Ctrl+Shift+F10`
不透明度、混合模式下拉（16 项）、「挖空组」、蒙版区：制作/释放不透明度蒙版、剪切/反转蒙版。

### 5.9 外观面板 `Shift+F6`
条目列表（填充/描边/效果可多条、可排序、可复制），「添加新填色」「添加新描边」「添加新效果」，每条有眼睛开关与混合模式。**实现映射见 01 篇 2.2**。

### 5.10 字符面板 `Ctrl+T` / 段落面板 `Ctrl+Alt+T`
字段与 AI 一致：字体/样式/大小/行距/字偶距/字距/垂直缩放/水平缩放/基线偏移/旋转/下划线删除线/语言/抗锯齿（无/锐利/犀利/平滑 → 映射 `-webkit-font-smoothing`）。

### 5.11 导出面板（本产品新增）
- 画板列表（多选 + 批量）、导出预设（PNG/JPG/SVG/PDF/HTML）、倍率 @1x/@2x/@3x/@4x
- 引擎选择：**原生 Vulkan（快）/ 浏览器真值（准）**
- 输出目录、命名模板（`{artboard}@{scale}x.{ext}`）
- 一键「导出 N 项」+ 进度条 + 完成后打开文件夹

## 六、画布区

| 元素 | 规格 |
|---|---|
| 画板 | 白底（可设背景色）、顶部显示画板名、`Shift+O` 可拖动/改尺寸、右上角 ⋮（导出此画板/复制/删除） |
| 画板外区域 | 比画布暗 8%，可设置「剪裁到画板外内容」 |
| 画板标尺 | 画板上方显示宽度标尺（AI 行为） |
| 网格 | 默认 8px 次要网格 + 64px 主要网格；`Mod+'` |
| 参考线 | 从标尺拖出，可锁定，支持"从对象生成参考线"（`Mod+5`） |
| 智能参考线 | 品红 `#FF00FF` 虚线 + 文字标注（间距/对齐/角度），与 AI 同色 ⭐ |
| 边界框 | 蓝色 `#3399FF`，1px；选中对象蓝色实线，悬停对象浅蓝 |
| 锚点 | 实心=选中，空心=未选；手柄线 1px，手柄端点 3px 方块 |
| 溢出标记 | 文本框右下角红点（文本溢出） |
| 冻结块 | 半透明 + 雪花角标，悬停提示"含不支持的 CSS，双击在代码视图编辑" |

## 九、验收点

- [ ] 窗口 < 1200px 时右侧自动折叠为图标条，无横向滚动条
- [ ] 所有数值框支持拖动 scrubby + 表达式输入
- [ ] 每个面板的 `F键` 显隐与 AI 一致
- [ ] 图层面板拖拽重排、跨编组、Alt 复制均可用
- [ ] 智能参考线颜色为品红 `#FF00FF`，行为与 AI 对齐（对齐/间距/角度三类提示）
- [ ] 深色/浅色主题切换无残留硬编码颜色（代码扫描：禁止 `fill: #xxxxxx` 字面量）
- [ ] 控制面板在 8 种工具态下显示正确字段
