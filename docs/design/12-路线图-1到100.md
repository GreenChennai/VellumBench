# 12 · 路线图 1 → 100

> v1.0 是"能用"，v2 是"别人做不到的"，v3 是"平台"。
> 排序原则：**先加深护城河（矢量 + AI 心智 + Agent），再扩边界（动效/协作/生态）。**

---

## 一、演进主线

```
v1.x  编辑力加深   组件 / 资产库 / 版式系统 / 数据驱动 / 路径进阶
v2.0  从静到动     动效时间轴（声明式关键帧 → CSS animation）
v2.x  平台化       原型 / 滚动叙事 / 插件(WASM) / 脚本宏 / 模板生态
v3.x  协作与多端   本地优先 CRDT / git 版本 / 触控笔 / Web(WebGPU) / macOS·Linux
```

## 二、v1.x — 编辑力加深

### v1.1 组件（符号）
- 主组件 + 实例；实例可覆盖属性（文本/颜色/图片），主组件改则全局同步
- 落点选择（三选一，spike 后定）：
  - **A. `<template>` + 构建期展开**（输出纯静态，无 JS）— 最"网页友好"
  - **B. Web Component（`<vsm-comp>`）**（需少量 JS）
  - **C. 纯 CSS class 复用 + 手工同步**（最弱但零成本）
  - 倾向 **A 为默认，B 为选项**
- 交互：与 AI 的符号面板一致（置入/断开链接/重新定义）

### v1.2 资产与样式库
- 跨文档资产库 `.vblib`：颜色令牌、字符样式、段落样式、组件、图形样式
- 与 CSS 变量的天然映射：库 = 一份 `:root` 变量表 + class 片段
- 从现有页面提取（可复用 WPI 的 `color_profiler` 思路扩展）

### v1.3 版式系统
- 基线网格、栏网格（12 栏）、间距刻度（4/8 倍数）
- 排版比例（字号阶梯生成器 → 输出 `--vb-font-1..6`）
- 对 HTML 的意义：网格直接落成 CSS 变量与工具类

### v1.4 数据驱动批量 ★ 高性价比
- 导入 CSV/JSON → 绑定到一个"重复模块"（组件 + 数据循环）
- 一次生成 20 个卡片 / 100 个商品项，且**保持可编辑**
- 输出：静态 HTML（构建期展开）+ 可选保留数据源
- 这是"人工 + 批量"的甜点区，Agent 场景极实用

### v1.5 路径与文字进阶
- 路径文本（SVG `textPath`）、文本绕排（CSS `shape-outside`）
- OpenType 特性面板（连字/花饰/数字样式/小型大写）
- 形状生成器、宽度工具、混合工具

## 三、v2.0 — 动效时间轴（从静到动的跃迁）

**目标**：在设计器里做关键帧动画，输出为 CSS `@keyframes`。

| 能力 | 落点 |
|---|---|
| 时间轴面板 | 画板底部的时间轴，轨道 = 对象属性（位置/缩放/旋转/不透明度/颜色） |
| 关键帧 | 打点、缓动曲线（cubic-bezier 可视化编辑） |
| 预览 | 画布内实时播放（Vello 逐帧） |
| 导出 | 原生逐帧 → FFmpeg（GIF/MP4），**不再依赖浏览器** |
| 输出 | `@keyframes` + `animation`；`prefers-reduced-motion` 自动降级 |
| 触发 | 载入 / 悬停 / 点击（纯 CSS）/ 滚动进入（v2.2） |

**为什么重要**：静态页 + 动效 = 80% 的落地页/活动页需求；而 WPI 存量用户本来就要导出 GIF/MP4，这条线把"编辑"和"导出动图"缝在一起。

## 四、v2.x — 平台化

| 版本 | 主题 | 要点 |
|---|---|---|
| v2.1 | **交互原型** | 页面/状态切换、热区连线、预览模式；输出纯 CSS 交互 + 可选极简 JS |
| v2.2 | **滚动叙事** | `animation-timeline: scroll()`、sticky 场景、滚动触发动画 |
| v2.3 | **插件系统** | WASM 沙箱 + 稳定 `vb_api`；插件可做：导入导出格式、面板、工具、效果 |
| v2.4 | **脚本与宏** | 命令回放 → 脚本（Rhai/WASM），支持批量处理；与 Agent 协议同源 |
| v2.5 | **模板与生态** | 模板格式（`.vstpl`，本质是工程 + 元数据）、本地模板库、分享（导出 zip） |
| v2.6 | **AI 入口** | 内置"交给 Agent"按钮：导出当前上下文 → 调用外部 Agent（MCP）→ 应用 patch。**不自接大模型 API** |

> v2.6 的设计直接呼应既有偏好：工具不接外部大模型，而是把 Agent 当外部驱动者。

## 五、v3.x — 协作与多端

| 版本 | 主题 | 要点 |
|---|---|---|
| v3.0 | **本地优先协作** | CRDT（`loro` / `automerge`）+ 可选自托管同步；离线可编辑，联网合并 |
| v3.1 | **版本历史** | ⭐ **用 git**：HTML 是文本，天然可版本化。内置 git 初始化/提交/分支/对比/回滚（调系统 git 或 `git2`） |
| v3.2 | **触控与压感** | 平板模式、手写笔压感（画笔/宽度工具）、手势（双指缩放/旋转） |
| v3.3 | **Web 版** | wgpu → WebGPU，浏览器内运行（只读/轻编辑优先） |
| v3.4 | **macOS / Linux** | Metal / Vulkan 后端适配，键位 `Cmd` 映射，打包分发 |

**v3.1 是本产品独有的红利**：因为没有私有二进制格式，版本历史、diff、code review、PR 全部可以直接用 git —— 这是 Illustrator/Figma 都给不了的。

## 六、生态与商业化（可选，不急）

| 方向 | 说明 |
|---|---|
| 免费核心 | 本地编辑 + 导出全部免费（与 WPI 的 MIT 开源气质一致） |
| 付费点 | 团队协作与同步、云端资产库、高级模板、优先支持 |
| 开源策略 | `vb_doc` / `vb_html` / `vb_css` 开源 → 吸引社区贡献 CSS 白名单扩展与 round-trip 语料 |
| 语料众筹 | 用户贡献"导入失败的页面" → 进 round-trip 语料库，持续提升兼容性 |

## 七、长期技术债管理

| 债 | 管理方式 |
|---|---|
| CSS 白名单扩展 | 每加一个属性 = 属性表条目 + 解析/生成 + 4 个测试（解析/生成/往返/渲染快照）；**不写测试不许加属性** |
| wgpu / Vello 升级 | 每季度一次"依赖升级日"，升级后必跑渲染快照与基准 |
| 文档格式演进 | `project.json` 带 `schema_version`，每次变更提供迁移器 + 旧版本测试样本 |
| 快捷键差异争议 | 保留"AI 实测记录"文档，任何与 AI 不一致处必须写明原因 |
| 性能回退 | 基准历史入库，回归 >10% 阻断合入 |

---

## 八、长期边界（仍然不做）

- 不做 CMS / 托管 / 建站服务
- 不做代码编辑器（VSCode 的事）；代码视图只读 + 最小编辑
- 不做 JS 运行时 / 前端框架编译（React/Vue 不纳入）
- 不做移动端原生 App
- 不接第三方大模型 API（AI 能力交给外部 Agent）

## 九、北极星检查点

| 阶段 | 检查问题 |
|---|---|
| v1.0 | 有没有人把它当主力工具改自己的页面？ |
| v2.0 | 有没有人用它做动效并直接导出？ |
| v2.5 | 有没有第三方做插件/模板？ |
| v3.0 | 有没有团队在上面协作？ |

任一阶段答案长期为"否"，应回头检查护城河（矢量精度 / AI 心智 / Agent 协议）是否没做扎实，而不是继续加功能。
